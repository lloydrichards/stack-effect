# Deploy with Alchemy

Alchemy deployment is optional. Select it through ordinary modules on a React, Foldkit or Cloudflare Worker target. The CLI generates target declarations and an editable root `alchemy.run.ts`. The CAFE recipe connects the Website and API Worker in that file.

## Select applications

A frontend alone:

```sh
stack-effect create website --yes --target client-foldkit/web:alchemy-client-foldkit-website
```

A Worker alone:

```sh
stack-effect create backend --yes --target cloudflare-worker/api:alchemy-worker-deployment
```

Create a CAFE app with Cloudflare, Alchemy, Foldkit, and Effect:

```sh
stack-effect create application --yes --target workspace/root:workspace-alchemy-cafe
```

The CAFE module adds `client-foldkit/web` with the Worker HTTP client and Alchemy Website, and `cloudflare-worker/api` with the Alchemy Worker deployment. The generated Stack passes the API Worker URL to the Website as `VITE_SERVER_URL`. The HTTP client module adds the shared API contract, and the Worker target supplies its handlers.

To choose different target names or use React, select the deployment and HTTP client modules directly and compose the Stack manually.

Deployment modules support Bun and Node. Add `--runtime node --package-manager npm` for Node/npm projects. Projects that omit these modules retain their existing development setup.

## Compose the root Stack

When you select deployment modules directly, add imports for your declarations and replace the empty `Applications` declaration. Keep the generated providers, state and `Alchemy.Stack` configuration.

For a frontend alone:

```ts
import Website from "./apps/client-foldkit-web/alchemy";

const Applications = Website().pipe(Effect.map((web) => ({ web: web.url })));
```

For a Worker alone:

```ts
import Worker from "./apps/cloudflare-worker-api/alchemy";

const Applications = Worker.pipe(Effect.map((api) => ({ api: api.url })));
```

To connect them:

```ts
import Website from "./apps/client-foldkit-web/alchemy";
import Worker from "./apps/cloudflare-worker-api/alchemy";

const Applications = Effect.gen(function* () {
  const api = yield* Worker;
  const web = yield* Website({ VITE_SERVER_URL: api.url.as<string>() });
  return { api: api.url, web: web.url };
});
```

Use the actual generated paths when naming targets differently. You can add queues, databases and other Alchemy resources to this same Stack. The CLI preserves modified declarations as file conflicts; repeat additions with `--yes` skip those conflicts. It does not rewrite your registrations or store a second binding configuration.

## Run infrastructure

From the generated workspace, run `bun run infra:check`, then `bun run infra:dev`. Use `npm run` in Node projects configured with npm.

For CAFE, open the Website URL printed by Alchemy and click **Call REST API**. The API Worker returns a response that the Foldkit app decodes with the shared Effect schema. The response panel shows `"message": "Hello Effect!"` and `"success": true`.

The root also exposes `infra:plan`, `infra:deploy` and `infra:destroy`, initially using the `dev` stage. Edit the scripts or invoke Alchemy directly for other stages. Alchemy and its frontend integration are pinned to `2.0.0-beta.87`.

Local development uses local state. Account-backed plan, deployment and cleanup require a configured Cloudflare profile and may create resources. The initial Worker implements the shared health and hello HTTP contracts; Worker RPC, SQL, chat and presence adapters are outside this version.
