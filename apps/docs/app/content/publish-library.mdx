# Create a publishable library

Add a small ESM library to an existing Stack Effect project with a Bun or Node runtime:

```sh
stack-effect add --target package/sdk:package-library
```

Use a new package name. This starter has one root entry point and no child modules. It creates these files under `packages/sdk`:

```text
package.json
package.publish.json
README.md
tsconfig.json
tsconfig.build.json
scripts/clean.mjs
scripts/prepare-package.mjs
src/index.ts
```

The workspace package stays private and exports TypeScript source for local use. `package.publish.json` owns the npm publication metadata. The build copies that manifest into `dist/package.json`, beside the compiled JavaScript and declarations.

## Add your public API

Add implementation files under `src/` and export them from `src/index.ts`:

```ts
export { greet } from "./greet.js";
```

Keep `.js` extensions in relative imports and exports. TypeScript resolves these paths to source files and emits imports that work in Node.

Published consumers import the library through its npm name. Add explicit entries to `package.publish.json` when you need public subpaths.

## Build and pack

Install the workspace dependencies, then run this command from `packages/sdk`:

```sh
npm run pack
```

The command rebuilds the library and packs `dist/`. Each build removes previous output, checks NodeNext module resolution, emits JavaScript and declarations, and copies the publication manifest and documentation. Node and npm are required for packaging, including in a Bun workspace.

Use `npm run build` to inspect `dist/` without creating a tarball. The tarball exposes one compiled root export and declares Effect as a peer dependency. Remove the peer entry from `package.publish.json` if your public API does not use Effect.

## Prepare publication

Set your npm name, version, license, description, and repository in `package.publish.json`. Add a `LICENSE` file beside that manifest; the build copies it into `dist/` when present. The workspace package can keep its private `@repo/sdk` name.

Install the tarball in a separate project and check runtime imports and declarations. Keep unpublished workspace dependencies out of emitted files. The generated README includes the publication checklist.

After reviewing the tarball, publish the compiled package:

```sh
npm publish ./dist
```

Publish `dist/`, which declares public npm access. The workspace root package remains private. Stack Effect does not publish automatically.

Repository maintainers can run `bun run --cwd apps/cli verify:library` to test generated Bun and npm libraries in clean consumers. It checks the packed JavaScript and declarations, private subpaths, and stale-output cleanup. All temporary projects are removed afterward.
